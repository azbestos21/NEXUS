# NEXUS

AI-powered visual research and knowledge intelligence workspace.

## Phase 1

Frontend product shell with:

- Landing page
- Workspace dashboard
- Three-panel research workspace
- Mock sources, knowledge graph (React Flow), and AI assistant

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
